# 🎓 College Mate

College Mate is an AI-powered college assistant designed to help students
quickly find college-specific information.

Instead of searching through multiple notices, documents, and webpages,
students can simply ask a question and receive an answer based on the
college knowledge base.

## 🚀 Features

- College-specific AI assistant
- Retrieval-Augmented Generation (RAG)
- College information search
- Sports and cultural event information
- Technical event information
- College facilities and locations
- Department and faculty information
- Handles unknown and out-of-scope questions
- Prevents the AI from answering using unrelated general knowledge

## 🧠 How It Works

```text
Student Question
       ↓
College Mate Backend
       ↓
Knowledge Base Search
       ↓
Relevant College Information
       ↓
Gemini AI
       ↓
College-specific Answer
